# Challenge 2: Does Verification Deter Participation?

This repository is scoped to **Challenge 2** from the AMC Research Sprint (April 13–14, 2026).

- **Part A (empirical):** Data analysis using the AMC datasets — the core deliverable.
- **Part B (optional):** Draw analogies between findings and AI governance debates; explain your reasoning.

Full specification: [`02_verification_participation.md`](02_verification_participation.md).

**Starter datasets:** `agreement_info`, `vercom`, `weapons_facilities` (see [`data/README.md`](../data/README.md)).

**Analysis script:** run [`data_analysis.py`](../data_analysis.py) from the repo root after installing dependencies (`pip install -r requirements.txt`).

Deliverable: a **policy brief**, alongside a cleaned, documented analysis for Part A.
